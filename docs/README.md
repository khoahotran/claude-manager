# Documentation index

All project documentation lives here, grouped by kind. The project overview is in the [root README](../README.md);
third-party attributions are in [`THIRD-PARTY.md`](../THIRD-PARTY.md) at the repository root.

| Folder | Contents |
|---|---|
| [`architecture/`](architecture/README.md) | Design, REST contract, security rules |
| [`planning/`](planning/README.md) | Feature list and roadmap, known issues, user feedback log |
| [`specs/`](specs/README.md) | Milestone specifications (contracts between backend and UI) |
| [`research/`](research/README.md) | Research digests that fed the design |

Where to start:
- New to the project: [`architecture/DESIGN.md`](architecture/DESIGN.md), then [`planning/FEATURES.md`](planning/FEATURES.md).
- Code maps: [`src/README.md`](../src/README.md) (backend), [`web/README.md`](../web/README.md) (frontend), [`tests/README.md`](../tests/README.md).
- What is broken or open: [`planning/KNOWN-ISSUES.md`](planning/KNOWN-ISSUES.md).

Conventions: documentation is written in English; use plain hyphens ("-") rather than long dashes; relative links only.
